# Feature map

One file per user-facing feature. Start with the top 3-5 flows from the spec's flow map. Each feature file has these four sections:

## Sub-features
## How to get to it (user POV)
## Driving it with the harness
## Gotchas

If the seed data lacks a precondition, the journey reports a failure and the reason goes under Gotchas. Never weaken a journey to make it pass.
